JavaScript 基础数据类型

6种原始数据类型详解与演示

1. String（字符串）文本类型

用于表示文本数据，可以使用单引号、双引号或反引号包裹

// 字符串的多种定义方式 let str1 = 'Hello World'; // 单引号 let str2 = "JavaScript"; // 双引号 let str3 = `模板字符串`; // 反引号 (ES6) let str4 = ''; // 空字符串 let str5 = '123'; // 数字字符串 console.log(typeof str1); // 输出: string console.log(str1.length); // 输出: 11 (字符串长度)

2. Number（数字）数值类型

用于表示整数和浮点数，还包括特殊值：Infinity、-Infinity、NaN

// 数字的多种形式 let num1 = 42; // 整数 let num2 = 3.14; // 浮点数 let num3 = 0xff; // 十六进制 let num4 = Infinity; // 正无穷大 let num5 = NaN; // Not a Number (非数字) console.log(typeof num1); // 输出: number console.log(10 / 0); // 输出: Infinity console.log('abc' * 2); // 输出: NaN

3. Boolean（布尔值）逻辑类型

只有两个值：true（真）和 false（假），常用于条件判断

// 布尔值的定义与使用 let isTrue = true; let isFalse = false; let isEmpty = false; let isValid = true; console.log(typeof isTrue); // 输出: boolean console.log(5 > 3); // 输出: true console.log(10 === '10'); // 输出: false (严格相等)

4. Undefined（未定义）缺失类型

变量已声明但未赋值时的默认值，表示"缺少值"

// Undefined 的使用场景 let undefinedVar; // 声明但未赋值 let explicitUndefined = undefined; // 显式赋值为undefined console.log(typeof undefinedVar); // 输出: "undefined" console.log(undefinedVar); // 输出: undefined console.log(undefinedVar === undefined); // 输出: true

5. Null（空值）空对象类型

表示"无"、"空"或"未知"的特殊值，表示有意设置为空

// Null 的使用场景 let emptyValue = null; let noData = null; let objectNotFound = null; console.log(typeof emptyValue); // 输出: "object" (历史遗留问题) console.log(emptyValue); // 输出: null console.log(emptyValue === null); // 输出: true console.log(null === undefined); // 输出: false

6. Symbol（符号）唯一标识符 (ES6)

ES6新增类型，表示唯一的、不可变的值，常用于对象属性标识符

// Symbol 的创建与使用 let sym1 = Symbol('description'); let sym2 = Symbol('description'); let sym3 = Symbol(); console.log(typeof sym1); // 输出: "symbol" console.log(sym1 === sym2); // 输出: false (每个Symbol都唯一) console.log(sym1.toString()); // 输出: Symbol(description) // Symbol 作为对象属性 let obj = { [sym1]: 'Symbol属性值' }; console.log(obj[sym1]); // 输出: "Symbol属性值"
