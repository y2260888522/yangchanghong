JavaScript 两种定时器

setTimeout 延时执行一次　·　setInterval 每隔一段时间重复执行

1. setTimeout只执行一次

语法：setTimeout(要执行的函数, 毫秒数)。它会在指定毫秒之后执行一次回调，返回一个定时器 ID；用 clearTimeout(ID) 可以在执行前取消它。

var id = setTimeout(function () {
  console.log("3 秒到了，只执行这一次");
}, 3000);

// 想取消就用 clearTimeout
clearTimeout(id);
尚未开始，点击「开始延时」体验一次延时执行

2. setInterval重复执行

语法：setInterval(要执行的函数, 间隔毫秒数)。它会每隔指定毫秒执行一次回调，同样返回一个定时器 ID；用 clearInterval(ID) 停止它。下面是一个每秒走一格的计时器。

var id = setInterval(function () {
  seconds++;              // 每 1000 毫秒执行一次
  render();
}, 1000);

// 想停止就用 clearInterval
clearInterval(id);
00:00:00

两种定时器对比

  • setTimeout：延时到点后只执行一次，适合做延迟操作、提示自动消失
  • setInterval：按固定间隔一直重复执行，适合做时钟、轮播图、数据轮询
  • 两者都返回定时器 ID（浏览器中为数字），必须用对应的 clearTimeout / clearInterval 清除
  • 间隔时间单位都是毫秒（ms），1000 毫秒 = 1 秒；实际触发时间会有轻微误差
  • 页面关闭或刷新时，所有定时器自动失效
