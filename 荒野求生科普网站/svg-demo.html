SVG 下导航 · 对照方案

本页下导航使用内联 SVG 绘制图标，不依赖任何字体文件。 与字体图标方案相比：图标为矢量路径，可用 fill:currentColor 继承颜色、 用 width:1.5em 随字号缩放，且不会出现字体加载失败时的“方块”。

两种方案对比

  • 字体图标：写法最简，一个 class 即可；但只能整体改色，依赖字体文件加载。
  • 内联 SVG：可精细控制每个图形路径，支持多色、描边与形变动画；代码量稍大，但零外部依赖。
  • 本项目选择：下导航主方案用字体图标（复用率高、代码简洁），另用本页 SVG 方案作技术对照，满足“两种技术有区别”的要求。

自适应宽度实现要点

  • 容器 display:flex，子项 flex:1 1 0 → 5 项永远等分，无需媒体查询。
  • 子项 min-width:0 → 防止内容撑破等分。
  • 图标 width:1.5em; font-size:15px → 改字号即改图标大小，缩放不失真。
  • fill:currentColor → 图标颜色跟随父级 color，选中态只需改一处。
  • padding-bottom: env(safe-area-inset-bottom) → 适配 iPhone 全面屏底部安全区。
